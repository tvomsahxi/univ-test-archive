# 問題集アーカイブ（univ_test_archive)

大学のオンライン授業などで出された問題を、教科（題材）× 授業回（サブ題材）で整理して保存し、いつでも復習できる 4択問題集アプリです。Flutter 製で iOS / Android / Web で動作します。

## 機能

- **問題の新規作成**: 問題文（テキスト＋任意で画像）、4つの選択肢、正解の丸付け、解説を登録
  - 正解は1つでも複数でも可（常に複数選択形式で、正解が1つの問題も同じ UI で扱う）
- **題材によるカテゴライズ**: 題材（例: 教科）→ サブ題材(例: 第1回〜) の2階層
  - 問題作成時に「既存の題材から選ぶ（モーダル）」か「新しい題材を作る」かを選択可能
- **出題**:
  - 題材を選んで開始 → 題材内の全問題からランダム出題（開始時に出題数の上限を指定可能）
  - サブ題材を選んで開始 → そのサブ題材の問題のみランダム出題
  - 回答すると正解 / 不正解と解説を表示、最後に正解数と正答率を表示
  - 採点は「正解の選択肢を過不足なくすべて選んだときだけ正解」（部分点なし）
- **問題一覧**: 題材 / サブ題材ごとに問題を確認し、タップで編集、ゴミ箱アイコンで削除
- **解答履歴**: 出題で回答するたび、解答日時と正誤を問題ごとに記録。問題一覧で
  直近の解答日・正誤・通算成績を確認できます
- **保存**: すべての変更は即座に JSON として保存され、次回起動時に読み込まれます

## デザイン

マテリアルデザイン（Material 3）を土台に、フランク・ロイド・ライトのプレーリー様式の
エッセンスを取り入れています。

- **直線の交差**: 角丸を全面的に排し、矩形で構成。一覧の行は左辺の縦帯が下辺の罫線と
  直角に交わり、見出しは方形の小片と太さの異なる二本の水平線が重なる
- **水平性の強調**: 見出し・仕切り・結果表示に水平の帯を通し、プレーリー様式が重んじた
  「地平線」の感覚を与える
- **アートグラス**: ホームと結果画面の上部に、縦の方立と横の桟が直交し交点に色ガラスの
  小片が並ぶ帯を配置（`ArtGlassBanner`）。等間隔の反復ではなく、間（ベイ）ごとの
  粗密で律動を作っている
- **大地の色**: チェロキーレッド（ライトの象徴色）を主、黄土色と草原の緑を副とし、
  羊皮紙色の地に載せる

配色とテーマは `lib/theme/prairie_theme.dart`、装飾要素は `lib/widgets/prairie.dart` に
まとめてあります。

## データの保存先

| プラットフォーム | 保存先 |
|---|---|
| iOS / Android / デスクトップ | アプリのドキュメントディレクトリ内 `univ_test_archive/questions.json` |
| Web | ブラウザの `localStorage`（ファイルシステムが無いため） |

どちらも同じ JSON 形式なので、「データ管理」画面（ホーム右上のアイコン）から JSON を
書き出し / 読み込みして、端末間でデータを移行できます。

### 書き出し

ファイル名は上書きを避けるため `questions-YYYYMMDD.json` と日付入りになります。

| プラットフォーム | 動作 |
|---|---|
| Web | ブラウザのダウンロードとして保存 |
| iOS / Android | OS の共有シートを開き、保存先を選択。「ファイルに保存」で本体、「Google ドライブ」等のアプリを選べばクラウドへ |

クリップボードへのコピーも用意してあり、テキストとして貼り付けて移行したいときに使えます。

Google ドライブへの自動同期（共有シートを経由しない直接アップロード）は未実装です。
実装する場合は Google Cloud プロジェクトと OAuth クライアント ID の用意が別途必要になります。

画像は Base64 として JSON に埋め込まれます（画像の利用が少ない前提の設計です）。

## 開発

```bash
flutter pub get
flutter test                    # ユニット / ウィジェットテスト
flutter test --platform chrome  # Web 固有の不具合を検出するため必ず実行
flutter analyze
flutter run -d chrome # Web で起動
flutter run           # 接続中の iOS / Android 端末で起動
flutter build web     # Web 用ビルド（build/web に出力）
```

## JSON スキーマ（version 2）

version 2 で解答履歴 `answers` を追加しました。`answers` を持たない version 1 の
JSON もそのまま読み込めます（履歴なしの問題として扱われます）。

解答履歴は 1 問あたり最新 100 件までを保持し、それを超えたぶんは古いものから
捨てられます（JSON が際限なく膨らむのを防ぐため）。

```json
{
  "version": 2,
  "topics": [
    {
      "id": "t-...",
      "name": "情報科学概論",
      "subTopics": [{ "id": "s-...", "name": "第1回" }]
    }
  ],
  "questions": [
    {
      "id": "q-...",
      "topicId": "t-...",
      "subTopicId": "s-...",
      "text": "問題文",
      "imageBase64": null,
      "choices": [
        { "text": "選択肢1", "isCorrect": true },
        { "text": "選択肢2", "isCorrect": false },
        { "text": "選択肢3", "isCorrect": false },
        { "text": "選択肢4", "isCorrect": false }
      ],
      "explanation": "解説",
      "answers": [
        { "answeredAt": "2026-09-21T09:13:05.438", "isCorrect": false }
      ],
      "createdAt": "...",
      "updatedAt": "..."
    }
  ]
}
```
